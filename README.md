# arjunalapsapkota.github.io

Personal portfolio for Arjun Sapkota. Plain HTML, CSS and JavaScript, hosted free on GitHub Pages at https://arjunalapsapkota.github.io

## Before you share the link

1. **Add your photo:** save it as `assets/img/photo.jpg` (portrait, roughly 960×1120 px or larger, under 500 KB). Until then the page shows your initials.
2. **Add your resume:** save it as `assets/Arjun-Sapkota-Resume.pdf`. The "Download Resume" button points to that file.
3. **Check your city:** it's in `index.html` inside `<span data-city>`.
4. **Check the content:** job descriptions in `index.html` are written from your background. Edit them to match your resume.

## Edit and publish

Change any file and commit to the default branch. GitHub Pages redeploys in about a minute.

```
git add .
git commit -m "Update portfolio"
git push
```

If the site isn't live: repo **Settings → Pages → Build and deployment**, set Source to *Deploy from a branch*, and choose your default branch and `/ (root)`.

## Structure

```
index.html              page content and SEO metadata
assets/css/style.css    all styling
assets/js/main.js       contact form, copy email, scroll animation
assets/img/photo.jpg    your photo (you add this)
assets/Arjun-Sapkota-Resume.pdf   your resume (you add this)
```
