# arjunalapsapkota.github.io

Personal portfolio for Arjun Sapkota. Plain HTML, CSS and JavaScript, hosted free on GitHub Pages at https://arjunalapsapkota.github.io

## Still to add

- **Photo:** save it as `assets/img/photo.jpg` (portrait, roughly 960×1200 px, under 500 KB). Until then the page shows your initials.

## Updating the resume

The "Download Resume" button serves `assets/Arjun-Sapkota-Resume.pdf`. To update it, replace that file with the new PDF using the same name.

## Edit and publish

Change any file and commit to the default branch. GitHub Pages redeploys in about a minute.

If the site isn't live: repo **Settings → Pages → Build and deployment**, set Source to *Deploy from a branch*, and choose `master` and `/ (root)`.

## Structure

```
index.html                         page content and SEO metadata
assets/css/style.css               all styling
assets/js/main.js                  contact form, copy email, scroll animation
assets/img/photo.jpg               your photo (you add this)
assets/Arjun-Sapkota-Resume.pdf    resume served by the download button
```
